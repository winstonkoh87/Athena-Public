# Interactive Demos & Visual Walkthroughs (`examples/demos/`)

This directory contains runnable HTML demos, terminal recording walkthroughs, visual architecture snapshots, and an example analytics report.

## Contents

- [demo.html](demo.html) — Interactive terminal session preview (`/start` -> work -> `/end`)
- [knowledge_graph_demo.html](knowledge_graph_demo.html) — Interactive vis-network knowledge graph explorer
- [DEMO_SCRIPT.md](DEMO_SCRIPT.md) — Step-by-step script for recording an Athena terminal demo GIF
- [ANALYTICS_REPORT.md](ANALYTICS_REPORT.md) — Sample knowledge infrastructure metrics & VectorRAG snapshot
- `demo.webp` / `demo_screenshot.png` — Animated terminal capture and static fallback screenshot
- `graphrag_visualization.png` — VectorRAG topology snapshot referenced in [ANALYTICS_REPORT.md](ANALYTICS_REPORT.md)
